Habit tracker online

Toque num quadradinho: uma vez para feito, duas para pulado, três para apagar.

Teclado: as setas se movem, Enter ou Espaço marca o dia. Salvo só neste navegador. Se você limpar os dados de navegação, ele se perde.

Cor

Como funciona

  1. Um toque por dia

    Toque num quadradinho uma vez para feito e duas para pulado; o terceiro toque apaga. Dias pulados não quebram a sequência.

  2. Fica neste navegador

    Nada é enviado e não há conta. Seus hábitos ficam salvos neste aparelho, neste navegador, até você apagar ou limpar os dados de navegação.

  3. Veja o ano e exporte

    A visão Ano mostra cada hábito como um ano inteiro de quadradinhos. Exportar PNG desenha tudo sobre fundo branco, pronto para compartilhar ou imprimir.
